# WEB1 Assignment 6 — jQuery

This project was created for Web Technologies Assignment 6 at Astana IT University.

## Description

The project demonstrates basic jQuery features, including DOM manipulation, event handling, effects, and animations.

## Project Structure

- **Part 1:** jQuery Setup, Selectors and CSS
- **Part 2:** Visibility, Fade and Slide Effects
- **Part 3:** DOM Manipulation and Form Interaction
- **Part 4:** Basic, Sequential and Combined Animations
- **Part 5:** Interactive jQuery Mini Project

## Technologies Used

- HTML
- CSS
- JavaScript
- jQuery

## How to Run

Clone or download the repository and open the HTML files in your browser.
